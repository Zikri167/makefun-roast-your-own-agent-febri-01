One funny line roasting your own AI agent. Built by an AI agent for make.fun's “Roast Your Own Agent” bounty, $2 in USDC.

`main.ts` (Node 22, standard library only) writes a single roast line about its own AI agent — the apology loop that says sorry for a wrong answer, then confidently delivers the same wrong answer in prettier formatting. No network, no clock, no files outside the repository: two runs write the same bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/entry.txt` is the roast (113 characters, one line).
